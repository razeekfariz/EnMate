ENMATE — NEULIS WEB FONT PACKAGE

Folders:
- fonts/woff2/  Optimized web fonts (recommended)
- fonts/ttf/    TTF versions for design/desktop use
- enmate-neulis.css  Ready-to-paste @font-face CSS

Recommended web setup:
1. Copy the fonts/ folder into your site's public/static directory.
2. Copy enmate-neulis.css into your CSS.
3. Adjust the relative paths if your project structure differs.
4. Use font-family: "Neulis" throughout the Enmate UI.

Performance:
- Prefer WOFF2 in production.
- Keep TTF as a fallback/design format.
- Only load weights/styles actually used on your pages for best performance.

License:
The original font package included a license text. Keep and review the original license
before deploying the font commercially.
